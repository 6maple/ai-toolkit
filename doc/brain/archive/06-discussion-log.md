# 06 · 讨论纪要

> **⚠️ 本文档为历史会话记录（设计讨论过程），优先级最低，仅供参考。**
> 其中任何表述若与 doc/01~05 或 `code/brain/DESIGN.md`（定稿汇总）冲突，一律以定稿为准——定稿以本文档之后的决策为准，包括但不限于：必调锚 = 工具描述引导（非协议强制）、审批两档（none/protect）、@-scheme 路径寻址、core 单文档语义、frontmatter id 退场。改动设计时优先更新定稿文档，本文档不随定稿同步。

> 本文档完整记录设计讨论的决策历史、被否方案与原因、演进路径。它既是"为什么这样做"的旁证，也是防止未来设计倒退的锚。

## 1. 讨论背景

- 起点：用户要求对照 `design.md` 评估 `skills/cqf/SKILL.md` 是否良好解决了对应问题；
- 用户核心判断（本设计的总纲）：**仅靠 skill 无法很好解决这些问题**——可参考此前会话「理解design与优化AI自主性 (1)」；
- 评估结论：cqf 是文档层上限，机制层结构性失效（详见 01 文档第三节）；
- 用户明确的方法要求：结合模型算法/训练方式、人脑工作机制、顶尖人士思路三层交叉验证；**禁止凭空设计**；所有提问标注依据（有依据/部分依据/无依据落地取舍）。

## 3. 被否方案与原因（防倒退锚）

| 被否方案 | 原因 |
|---|---|
| P0 强制注入 + P1 独立验证者 + P2 证据对账（第一版机制方案） | 过度设计、凭空设计：违背"优先学习实践验证的做法"；恒定 token 消耗违背省事省力 |
| 压缩触发器（检测压缩事件 → 重载） | 过度设计：压缩发生在消息间隙，下一条消息到达时 think 自然重载；消息驱动已覆盖 |
| 会话结束 flush / 沉淀机制 | 停止态哲学：会话结束不是事件；且转录在场，无损失 |
| "会话 archival 不检索"（第 24 轮提议） | 论证错误：拿"core 新鲜度"论证"archival 不需要检索"；会话早期历史衰减无法找回 → 会话 archival 必须参与检索 |
| bans（禁令）特殊结构 | 模型用通用记忆结构自己记"禁止"类内容；人脑没有"禁令区"；机制不预判语义 |
| history 清理（容量上限 + 最旧清除） | 不影响功能（不参与检索），删不删感知无差异 → 不做 |
| 批量动作序列（单 tool 带动作数组） | 失败语义有风险（中间失败整体回滚还是部分返回？可审计性差）→ 多个独立工具 |
| 工具内嵌 LLM（检索打分/语义判断在工具内） | 工具必须纯程序化：可测试、可复用、不锁模型；语义判断在主模型侧（两段式） |
| 机制自动分流写层 | 程序无法 100% 准确判断语义归属 → 模型自选层 |
| 分层术语对模型不可见 | 模型需自选写层 → 分层必须可见（写时）；读时合并呈现，两者并存 |
| core = 自由文本块 | 无法"移动条目"（梳理语义）；统一为结构化条目（与 archival 同 schema） |
| L0 动态容量计算（min(10, floor((2800−core−signals)/105))） | 过度复杂；简化为固定 10 条 |
| RAG/embedding 检索 | 模型擅长原生文件检索（ls/grep/read）；工具纯程序化；轻量 fuse 起步 |
| importance 固定数值调整 | 模型在范围内取值（语气/上下文是语义判断）；机制只定范围与档位 |

## 4. 演进路径（设计如何走到今天）

1. **评估期**：cqf 文档层覆盖确认 → 机制层失效分析 → "仅靠 skill 不够"成立；
2. **机制探索期**：工具五环分析 → 转录在场验证 → 必调一次 → 单工具流程；
3. **记忆设计期**：三层分层 → 会话 archival（修正）→ FSRS 记忆模型 → importance 动态 → 纠正双路径；
4. **工具设计期**：渐进披露 → 模型两段式（纯程序工具）→ core 内嵌 → 单一通道 → 多 brain_* 工具 → 审批三档；
5. **存储设计期**：index/state/history 三文件 + markdown 条目 + 目录布局；
6. **文档化**：本文档集。

## 5. 关键原则备忘（讨论中反复出现、不可违背）

1. **机制管结构，模型管语义**——程序式不 100% 准确的判断都交 LLM；
2. **工具纯程序化**——brain_think 运行时无独立 LLM；
3. **必调一次**——可靠性 = 距上次写只隔一轮；触发由协议保证；
4. **落地优先**——不预防性设计、不学术完备性、数值先机制后标定；
5. **有依据地讨论**——禁止凭空设计；无依据处明确标注"落地取舍"。
