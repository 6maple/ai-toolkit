# 本轮交付

按以下要求整理准备交付的实际内容。

依据同一State的最新有效成果，向用户交付本轮需要的回答、分析、方案、文件或实际工作结果，并说明相关认识、验收范围及续作安排，引用实际成果和记录位置。具体组织与呈现方式按任务和用户需要选择；下方示例仅展示一种写法。

形成交付内容时发现需要新增或改变关键判断，先查明并修订State及受影响工作，核对后再交付。用户纠正某个节点或关系时，按实际影响修订相应链、结论和关联成果，保留仍有效部分。

## 深挖链

每个实际涉及深挖的部分，都呈现对应的具体深挖链，让用户能够指出哪个背景、事实、连接或判断需要纠正。包括意图理解、事情本质，以及工作中实际深挖的方法、方案或关键取舍。

按实际形成、目标具体化或判断的支持关系展开关键节点和连接。意图链说明相关背景、目标、条件怎样连接到本轮委托；本质链说明形成现象的条件与机制，或目标成立所需的条件；方法、方案等链说明哪些依据和约束支持相应选择。

必要依据或实际来源就近说明，区分用户明确要求、已取得的事实、推断和未知。保留关键分支及实际停止或未知边界；采用再追一层确认停止的，呈现采用层、直接上一层、两层关系及相应依据。尚未查明的上游保留待查及其影响。

关键分支说明实际关系，区分并列、择一或共同成立；汇合处说明哪些分支怎样共同支持或约束后续判断。

链只展示本次实际取得、供用户核对的关键关系；普通执行动作按实际结果表达。消息先后、工具调用顺序及通用流程不替代具体深挖链。

## 结果、未知与续作

说明本轮实际目标、必要条件、本次委托与有效范围，以及意图和本质的当前认识。处理依据交代当前意图、事实与方法选择、方案取舍及验收重点之间的关系。

当前成果说明实际交付了什么、对应什么目标、按什么依据核验、目标满足到什么范围，以及尚未验证的部分。关键未知说明具体缺口、受影响的判断或工作，以及可以继续与受限的范围。

未完成交接说明原阶段尚未完成、已有进展、具体暂停原因、受影响范围和恢复前提；只填写实际取得的内容。资料暂缺、等待决定、后续计划及本轮成果完成保持各自状态。

后续工作使用当前有效安排，写明仍需继续的事项、预期结果、验收目标与方式、推进安排及必要依赖。用户明确取消或已经完成的事项不列为待继续工作。用户介入只列确需其提供的事实、澄清、决定或授权，说明具体影响。

仅交付本次实际取得且与用户需要相关的内容；无相关内容的部分省略，会影响判断或续作的未知必须保留，不为凑齐内容补造节点或结论。
