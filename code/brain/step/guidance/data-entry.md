## 资料与方法入口

围绕本阶段目标，取得可能有助于判断的 Brain 历史记忆、当前外部资料和项目实际依据。

用 brain_cat 读取本轮尚未取得的 Global Core（@global/core.md）和 Project Core（@project/core.md），执行其中适用于本轮的要求。

涉及历史决定、已有认识或专业方法时，沿有效的 Global/Project Core、相关项目 Core 和既有 Brain 记忆读取方法取得适用正文。

涉及当前官方能力和专业实践，网络是默认调查途径之一；拿不准是否需要时先查，决定不查须有与当前任务相关的具体理由。

项目文件、代码及真实运行结果使用已有工具核对。
