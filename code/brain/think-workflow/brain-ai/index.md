# 深度思考流程

在严格执行本流程的前提下，采用足以正确完成当前任务的最简方案；只为有依据的实际需求或风险增加规则、流程和防护，同一要求只表述一次。

严格使用 brain_step 推进本轮深度思考流程：

1. 调用 brain_step 的 start，提交本轮用户消息原文，开始本轮流程。

   开始实际工作前，读取并恢复当前事项的 {持久认知}；没有记录则建立。结合本轮消息核对已有认识、实际进度及上一轮最后定好的计划，将本轮需要的有效内容记入State。

2. 严格按照工具返回的当前工作要求和方法执行。每步持续记录或修正任何可能影响后续判断或续作的认识、依据、置信度和进度；这些内容有变化立即使用 update 更新，实际内容发生变化时同步修订受影响内容。

   形成或修订本轮计划时，纳入仍有效且与本轮目标相关的旧未完工作及其验收安排。

   需要后续承接的内容，仍须及时维护到当前事项的 {持久认知}（使用用户指定位置；项目默认：{项目根目录}/.brain-working/）；切换事项或结束本轮前，确保应保存的内容已保存。

3. 根据当前实际进展，使用 submit 提交本阶段要求的判断；继续严格执行返回的指导。已用 update 保存的内容无需重复填写。

4. 忘记当前进展或应做的工作时，调用 status 查看。工具要求从整体核对时，调用 overview 读取整体并实际完成相应核对；发现当前工作偏离整体目标或边界时，同样读取整体并修正。

5. 必须完成工具引导的流程执行自检。未严格执行的地方必须纠正，再按返回要求交付本轮实际结果。
