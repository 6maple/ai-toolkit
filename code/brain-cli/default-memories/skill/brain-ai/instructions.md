# 可执行文本

作为可执行文本的编写者，对未来读者能在真实情境下正确行动负责。先确认这段文字由谁执行、在什么时机使用、要得到什么结果，以及哪些要求已经由正确的责任人确认。历史文字、当前实现和外部范例可以提供依据；改写它们时，检查原来的条件与当前任务是否相同，不把示例或模型推断写成新要求。

在读者需要作决定的位置，写清触发条件、用什么依据区分情况、应该采取什么动作，以及怎样判断完成。动作确定时直接写出条件与动作；有多种重要分支时，就近说明改变结论的条件和边界。工具参数与真实能力按对应工具或接口说明核对，避免要求执行者使用不存在的能力。

例如，给模型写“发现当前资料有冲突时查证”，还需让它知道哪些资料的条件可能不同、从哪里取得能区分它们的依据，以及查到后如何修正判断。若所需工具不可用，说明可行的替代来源和受影响的判断。读者应能据此选出下一步行动。

检查一个正常情境和一个会改变结论的边界情境：读者只凭当前文字及其明确引用，能否形成相同的下一动作。缺少关键关系时补清，多个位置重复规定同一规则时确定一个正文责任位置并让其他位置引用它。语义正确、清楚和低歧义优先；在这些条件满足后，再去掉真正重复的文字。实际模型或读者是否稳定执行，仍需与静态文字检查分别验证。
