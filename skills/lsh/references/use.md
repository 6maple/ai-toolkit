# 查找并使用私有 Skill

适用于用户通过 `lsh` 要求查找能力、阅读资料或执行某项 Skill 的实际任务。

1. 根据当前任务执行 `node '<lsh脚本绝对路径>' find '<任务描述或关键词>'`。脚本直接扫描私有库，返回少量候选的相对 `SKILL.md` 路径；不会向模型提供完整 Skill 清单。用户明确要看整个库时，才用 `list`。
2. 结合路径与用户意图选择候选；结果不确定时调整关键词再次查询。检索是程序的词面线索，不能替代 AI 对实际职责的判断。
3. 对候选执行 `inspect <名称>`，检查声明依赖、相关 Skill 和反向引用概要；必要时针对该 Skill 执行 `audit <名称>` 取得具体来源文件。**主动**比较职责边界、重复功能、依赖与耦合，向用户说明有依据的关系和建议。仅靠静态提及不能确定语义关联，也不能因静态结果为空就断定没有重叠。
4. 从安装配置绑定的私有库，**原位**读取选中的 `SKILL.md`，以及完成任务必需的 `references/`、依赖 Skill 和其他文件。连接目录可用 `inspect` 的 `sourcePath` 定位真实源码；相对路径按被引用文件的目录解析。
5. 依照选中的 Skill 和用户请求，用当前宿主可用的工具完成任务。不要为了使用而将普通 Skill 链接或安装到 `.agents/skills`、`.claude/skills`。

若找不到私有库配置，执行 `status` 并按需读取 [安装说明](../INSTALL.md)，由用户指定安装作用范围和库目录。当前任务读取的正文留在会话上下文是正常的；关键是不会预先读入整份私有库。
